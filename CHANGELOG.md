# Changelog

## 0.7.0 - 2026-09-19

- Move prompt notes into a dedicated Codex Partner Activity Bar view.
- Localize the complete prompt-notes Webview in English and Simplified Chinese.
- Add direct access to Codex Partner keyboard shortcut settings from the panel.
- Refine the rounded composer, remove the explicit character limit, and add an accessible top-edge resize handle.

## 0.6.0 - 2026-09-13

- 新增独立的本地内容记录侧栏，不连接 Codex 会话。
- 支持本地保存、复制、删除和清空内容记录。
- 优化侧栏布局：顶部历史列表、底部固定输入框，以及内嵌 SVG 保存按钮。

## 0.5.0 - 2026-09-05

- Add VS Code localization support with English as the default language and Simplified Chinese translations.
- Localize command titles, Quick Pick labels, notifications, errors, and generated workspace references.
- Update the Marketplace README with English-first product documentation.
- Optimize the Marketplace icon to reduce the extension package size.

## 0.4.0 - 2026-08-30

- Add a unified Quick Pick for searching and copying workspace file or directory references.
- Prioritize the 10 most recently used references and disambiguate multi-root workspace paths.
- Add the `Ctrl+Alt+R` shortcut and a Marketplace-ready Codex Partner icon.

## 0.3.0 - 2026-08-30

- Add default keyboard shortcuts for copying selection and file references.
- Add a command to open Codex Partner keyboard shortcut settings.
- Document the lightweight context-reference workflow for the official Codex extension.

## 0.2.0

- Simplify the extension to copy workspace-relative file, line, and directory references.
