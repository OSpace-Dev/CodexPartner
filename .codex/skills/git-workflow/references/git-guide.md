# Git 工作流参考

## 平台适配

| 场景 | 通用能力 | 可选平台能力 |
| --- | --- | --- |
| GitHub | Git over SSH/HTTPS | `gh`、Pull Request、Actions |
| GitLab 或局域网 GitLab | Git over SSH/HTTPS | `glab`、Merge Request、CI/CD |
| Gitee | Git over SSH/HTTPS | Gitee API 或网页协作 |
| 普通自建 Git | Git over SSH/HTTPS | 服务端提供的网页或 API |

平台能力必须以实际远端、认证和可用工具为准。不要因为域名类似就假设是某种兼容服务。

## 提交前检查

- [ ] 当前分支和任务目标正确。
- [ ] 已理解已修改、未跟踪和已暂存文件。
- [ ] 暂存区只包含当前任务内容。
- [ ] 已完成与风险相称的验证。
- [ ] 没有密钥、本机路径、调试数据和意外生成文件。
- [ ] 提交信息说明可观察结果。

## 推送前检查

- [ ] 目标远端和分支明确。
- [ ] 本地提交范围和上游差异已检查。
- [ ] Review、测试和分支保护要求已满足。
- [ ] 推送不会意外覆盖协作者历史。
- [ ] 用户授权和仓库规则允许本次推送。

```md

## 目的与范围

[为什么需要迁移、重写、切换远端或恢复历史。]

## 影响

- 提交范围：[说明]
- 协作者影响：[说明]
- 风险：[说明]

## 备份与恢复

- 操作前引用：[标签、分支或提交]

## 确认与结果

- 确认人：[填写]
- 实际结果：[填写]
- 验证：[填写]
```
