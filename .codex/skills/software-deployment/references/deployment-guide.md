# 部署参考与模板

## 部署计划模板

```md
# [部署主题]

编号：DEP-[YYYYMMDD]-[NNN]
目标环境：[开发 / 测试 / 预发布 / 生产 / 设备]
发布版本：[版本、提交或制品摘要]
对应测试：[TEST-[YYYYMMDD]-[NNN]]

## 变更内容

- [用户可见变化、服务变化、配置或数据变化]

## 准入检查

- [ ] 测试结论满足发布要求
- [ ] 目标环境和权限已确认
- [ ] 配置与密钥来源已确认
- [ ] 数据备份或迁移方案已确认
- [ ] 健康检查和回退方案可执行

## 执行步骤

1. [动作]
   - 预期：[状态]
   - 失败时：[停止或回退动作]

## 验收标准

- [健康、功能、日志、指标或人工观察条件]

## 回退

- 触发条件：[条件]
- 回退版本：[标识]
- 操作步骤：[步骤]
- 回退验证：[检查]
```

## 部署记录模板

```md
# [部署记录]

编号：DEP-[YYYYMMDD]-[NNN]
状态：[成功 / 失败 / 已回退 / 阻塞]
环境：[目标]
版本：[实际版本]
执行人：[填写]
开始 / 完成时间：[填写]

## 执行结果

| 阶段 | 状态 | 证据或说明 |
| --- | --- | --- |
| 预检 | [状态] | [日志或结果] |
| 制品校验 | [状态] | [SHA-256] |
| 构建与启动 | [状态] | [镜像或制品标识] |
| 健康检查 | [状态] | [证据] |
| 人工验收 | [状态] | [结果] |

## 异常与回退

- [异常、影响、处理和最终状态]

## 剩余风险

- [未覆盖项、监控事项或后续任务]
```

## 人工部署协议要求

无法自动化时，文档必须给出目标主机或设备的识别方式、前置状态、编号步骤、每一步预期结果、停止条件、回退步骤和结果填写区。不得要求用户执行含义不明的命令。
