# 软件评审参考

## 风险检查

根据变更类型选择相关检查项，不机械遍历无关内容：

- 正确性：正常路径、空值、边界、错误分支、状态转换和重复调用。
- 回归：既有行为、默认值、兼容入口、升级和降级路径。
- 契约：API、事件、文件格式、数据库模式、CLI 参数和配置语义。
- 安全：认证、授权、输入验证、敏感信息、注入、权限提升和供应链。
- 数据：一致性、事务、幂等性、迁移、精度、排序、时区和回滚。
- 并发与资源：竞态、锁、超时、取消、重试、句柄、内存和清理。
- 性能：复杂度、热点路径、批处理、网络调用、缓存和资源上限。
- 可观察性：错误是否可诊断，日志、指标和告警是否泄露信息或制造噪声。
- 测试：关键行为、失败场景和回归是否有有效覆盖，断言是否能真实失败。

## 发现模板

```md
## [P1] [简短问题标题]

- 发现编号：REV-[YYYYMMDD]-[NNN]-F[NNN]
- 位置：[文件和最小相关行]
- 触发场景：[输入、状态或执行顺序]
- 证据：[代码路径、测试结果或契约依据]
- 实际行为：[当前会发生什么]
- 预期行为：[需求、规范或既有契约要求什么]
- 影响：[用户、数据、系统或交付风险]
- 修复方向：[约束或建议，不直接提供未经验证的大段补丁]
```

## 报告模板

```md
# [评审主题]

编号：REV-[YYYYMMDD]-[NNN]
评审对象：[任务、提交、分支、差异或文件范围]
需求依据：[需求和决策链接]

## 发现

[按严重程度列出；没有时明确说明未发现阻断性问题。]

## 开放问题

- [需要产品、架构或实施者确认的问题；无则写无]

## 未检查内容

- [缺少环境、设备、数据或权限而未覆盖的范围；无则写无]

## 残余风险

- [评审后仍存在的风险；无则写无]

## 结论

[阻断 / 有条件通过 / 通过]

## 复审记录

- [发现编号]：[已解决 / 仍存在 / 已接受风险 / 无法验证]，[证据或说明]
```
