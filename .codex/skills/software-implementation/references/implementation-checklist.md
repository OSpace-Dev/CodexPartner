# 实施检查清单

## 开始前

- [ ] 当前任务编号、目标、范围和完成定义明确。
- [ ] 已读取适用的 `AGENTS.md` 和相关需求、决策、技术文档。
- [ ] 阻塞性问题已确认，低影响假设已声明。
- [ ] 已识别技术域和适用的专项 Skill 或项目规范。
- [ ] 已确定验证方法和必要回退路径。

## 编码中

- [ ] 改动保持最小、内聚，没有混入无关清理。
- [ ] 遵循现有架构、命名、错误处理和依赖模式。
- [ ] 行为变化有相应测试或其他可复现证据。
- [ ] 发现范围变化或高影响未知时已停止相关实现并请求确认。
- [ ] 没有覆盖来源不明的现有改动。

## 收口前

- [ ] 已运行与风险相称的测试、检查和构建。
- [ ] 已复核错误路径、兼容性、安全和技术域特有风险。
- [ ] 已更新必要文档和任务状态。
- [ ] 已记录未执行验证、剩余风险和后续事项。

需要独立测试或验证记录时，使用 `YYYY-MM-DD-NNN-topic.md` 命名，并在正文设置 `TEST-YYYYMMDD-NNN` 编号。编号分配后不得重排。
