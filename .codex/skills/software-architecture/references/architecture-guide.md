# 架构与设计参考

## 内容选择

| 设计层次 | 主要回答的问题 | 常见内容 |
| --- | --- | --- |
| 架构设计 | 系统边界和关键决策是什么 | 上下文、质量属性、组件边界、技术和部署决策 |
| 概要设计 | 各部分如何协作 | 组件职责、接口、数据流、部署、错误与安全边界 |
| 详细设计 | 某个复杂部分如何实现 | 模块结构、状态、时序、算法、并发、迁移和边界条件 |

## 图示规则

只在关系或时序用文字难以说明时使用图。图中的节点、接口和数据流必须与正文一致；图不能替代契约、失败行为和设计理由。引用仓库内容时只使用相对路径。
