# 测试参考与模板

## 测试方式矩阵

| 目标 | 首选方式 | 自动化不可行时 |
| --- | --- | --- |
| 纯函数和边界逻辑 | 单元测试 | 手工输入矩阵与结果记录 |
| API、事件和数据契约 | 接口或集成测试 | 使用固定请求、响应和日志证据手工核对 |
| 页面交互和视觉 | 浏览器自动化或组件测试 | 按页面路径逐步操作并截图 |
| 真实设备、硬件和时序 | 设备级或硬件在环测试 | 明确设备、固件、操作步骤和恢复方式 |
| 部署、权限和外部服务 | 环境化验收 | 使用隔离环境和可回退的操作清单 |

## 测试用例模板

```md
### TC-[YYYYMMDD]-[NNN] [用例标题]

- 对应需求：REQ-[YYYYMMDD]-[NNN]
- 风险等级：[高 / 中 / 低]
- 方式：[自动化 / 人工 / 组合]
- 前置条件：[环境、版本、账号、数据、设备]

#### 步骤

1. [操作]
   - 预期：[可观察结果]
2. [操作]
   - 预期：[可观察结果]

#### 通过标准

- [必须满足的条件]

#### 证据

- [日志、截图、录屏、输出或其他证据]

#### 结果

- 状态：[通过 / 失败 / 阻塞 / 未执行 / 不适用]
- 执行人：[填写]
- 执行时间：[填写]
- 备注：[填写]
```

## 人工测试协议模板

```md
# [人工验收主题]

编号：TEST-[YYYYMMDD]-[NNN]
对应任务：[TASK-[YYYYMMDD]-[NNN]]
对应需求：[REQ-[YYYYMMDD]-[NNN]]

## 目的

[需要由人工确认的用户行为、设备状态或环境结果。]

## 准备

- 环境：[版本、地址、设备或浏览器]
- 账号与权限：[准备方式；不要记录密码]
- 数据与初始状态：[准备方式]
- 回退方式：[失败后的恢复步骤]

## 执行步骤

1. [具体操作，不使用“正常操作”等模糊描述]
   - 预期结果：[观察什么]
   - 证据：[需要保留什么]
2. [具体操作]
   - 预期结果：[观察什么]
   - 证据：[需要保留什么]

## 验收标准

- 通过：[全部必须满足的条件]
- 失败：[任一出现即失败的条件]
- 阻塞：[无法执行的条件和需要谁决定]

## 回填

- 状态：[通过 / 失败 / 阻塞 / 未执行]
- 执行人：[填写]
- 执行时间：[填写]
- 证据位置：[填写]
- 备注：[填写]
```
