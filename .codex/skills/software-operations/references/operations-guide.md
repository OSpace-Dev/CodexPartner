# 运行维护参考与模板

## 运行手册模板

```md
# [运维主题]

编号：OPS-[YYYYMMDD]-[NNN]
目标环境：[受控环境名称]
目标服务或设备：[稳定标识]
部署版本：[版本或发布编号]

## 目的与影响

- 目的：[需要达到的运行结果]
- 预计影响：[无 / 降级 / 短暂停机 / 数据影响]
- 风险：[主要风险]

## 前置检查

- [ ] 目标和版本已确认
- [ ] 权限和备份状态已确认
- [ ] 停止条件和恢复方案可执行

## 操作步骤

1. [只读检查或操作]
   - 预期：[结果]
   - 停止条件：[异常]
   - 失败处理：[恢复或升级]

## 完成验证

- [健康、功能、日志、指标和数据检查]

## 回填

- 状态：[成功 / 失败 / 已恢复 / 阻塞]
- 执行人：[填写]
- 时间：[填写]
- 证据：[相对链接或受控系统记录]
- 后续事项：[填写]
```
