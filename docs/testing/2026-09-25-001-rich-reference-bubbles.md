## Extension Host 人工验收协议

### 准备

- 在 VS Code 打开仓库，按 `F5` 启动 `Run Codex Partner`，打开 Activity Bar 的 Codex Partner 面板。
- 准备以下文本：
  - `【File \`src/one/two/three/four.js\`, lines 2-4】`
  - `【文件 \`src/components/shared/index.js\`，第 8 行】`
  - 含普通文字、多个引用和多行文本的混合内容。

### 步骤与预期

1. 将上述引用粘贴到输入框。
   - 预期：引用显示为带文件/目录图标的紧凑圆角气泡；长路径显示后缀并以省略号截断；普通文字仍可编辑。
2. 将光标放在气泡前后输入文字，使用 Backspace/Delete 删除气泡。
   - 预期：气泡作为一个不可编辑节点被整体删除，不破坏相邻文字。
3. 点击保存，重新打开面板并查看历史记录。
   - 预期：历史记录展示相同气泡；内容未被截短或替换为视觉摘要。
4. 点击历史记录的复制按钮，在外部文本编辑器粘贴。
   - 预期：得到完整原始引用，包括完整路径和行号。
5. 在编辑器中选中包含气泡的内容并复制，在外部文本编辑器粘贴。
   - 预期：得到完整原始引用和原有普通文本。
6. 在简体中文和英文显示语言、浅色和深色主题、约 220px 窄侧栏下重复步骤 1–5。
   - 预期：气泡文案、图标对比度、换行和省略号均可读，控件不重叠。
7. 将气泡与普通文字放在同一行，鼠标悬停气泡，再使用 Tab 聚焦气泡及删除按钮。
   - 预期：气泡和文字垂直对齐；右侧删除按钮只在输入区的悬停或聚焦状态显示，点击或键盘激活后完整移除气泡并更新草稿；历史记录中不显示该按钮。
8. 悬停或聚焦长路径气泡，并滚动输入框及历史列表。
   - 预期：圆角提示位于气泡上方，展示完整原始引用，不被输入框裁切；滚动时位置随气泡更新。
9. 在浅色、暗色和暗色高对比度主题中检查气泡与提示。
   - 预期：气泡高度略低于同一行正文的行高；气泡内标签比正文小一档，标签和图标垂直居中，整体与外部文字视觉对齐；暗色提示为白底深字，底部箭头指向当前气泡。
