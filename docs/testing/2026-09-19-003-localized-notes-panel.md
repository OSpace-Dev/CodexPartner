## 人工验收协议

### 目的

核实面板随 VS Code 显示语言切换、主题图标与圆角、快捷键设置跳转，以及无计数输入的实际使用体验。

### 准备

- 使用 VS Code 打开仓库，按 `F5` 启动 `Run Codex Partner`，点击 Activity Bar 的 Codex Partner 图标。
- 准备英文与简体中文显示语言；切换语言需按 VS Code 提示重启 Extension Development Host。准备浅色和深色主题。
- 使用一次性测试记录；结束后在面板内删除它们，不清空其他已有记录。

### 执行步骤

1. 分别在英文和简体中文界面打开面板，查看标题、输入提示、历史区、按钮提示、空状态和复制/删除确认反馈。
   - 预期：文案与 VS Code 显示语言一致；没有未翻译的中文硬编码或空白提示。保留两种语言截图。
2. 切换浅色和深色主题，观察标题图标、输入区和操作按钮，并将侧栏缩至约 220px。拖动输入框上沿抓手向上增高、向下缩小，再使用 `Tab` 聚焦抓手并按上下方向键。
   - 预期：标题图标只有主题前景色笔画，没有蓝色方块；右下角没有原生缩放热区，顶部抓手可在 82–180px 内顺畅调整高度，重新显示面板后保留高度；键盘可调整且焦点可见。圆角边界连续，控件与文字不重叠。保留主题、窄侧栏和缩放状态截图。
3. 点击标题旁键盘图标。
   - 预期：打开 VS Code 快捷键设置，搜索或过滤 Codex Partner 相关项。记录实际跳转结果。
4. 输入普通多行文本，确认没有可见“新内容”标签和字数计数；粘贴超过 20,000 字符的测试内容并保存、重新打开面板、复制回来比较长度与内容。
   - 预期：输入不被旧上限截断，保存后内容可读取且复制结果一致；按钮和提示不遮挡文本。记录输入长度、复制结果和是否出现卡顿，不写入真实敏感数据。

### 验收标准

- 通过：四步均符合预期，无内容截断、主题或布局问题，快捷键设置可打开。
- 失败：任一步产生错误文案、蓝色方块、遮挡、跳转失败或内容丢失。
- 阻塞：无法启动开发宿主、切换语言/主题或访问快捷键设置，记录环境和阻塞原因。
