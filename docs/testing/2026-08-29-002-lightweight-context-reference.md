# 轻量上下文引用人工验收

测试编号：`TEST-20260829-002`

## 前置条件

- 已安装 VS Code。
- 当前工作区打开的是本仓库根目录。
- 已运行 `npm run check` 并通过。
- 官方 Codex VS Code 扩展已安装，用于粘贴结果验收。

## 步骤

1. 按 `F5` 启动 `Run Codex Partner`。
2. 在已保存文件中选择单行文本，点击灯泡并选择“复制 Codex 文件行号引用”。
   预期：剪贴板得到 `【文件 ...，第 N 行】`，并出现成功通知。
3. 选择跨多行文本，重复操作。
   预期：剪贴板得到正确的 `起始行-结束行` 范围。
4. 在资源管理器中右键一个文件。
   预期：出现“复制 Codex 文件引用”，复制结果不含绝对路径。
5. 在资源管理器中右键一个目录。
   预期：出现“复制 Codex 目录引用”，复制结果以目录相对路径表示。
6. 将任意复制结果粘贴到官方 Codex 扩展聊天框。
   预期：文本可直接作为 Codex 的上下文定位提示。
7. 在编辑器中选择文本并按 `Ctrl+Alt+C`。
   预期：复制选区的文件行号引用，并出现成功通知。
8. 取消文本选区并按 `Ctrl+Alt+F`。
   预期：复制当前文件引用，并出现成功通知。
9. 在 VS Code“键盘快捷方式”中搜索 `Codex Partner`。
   预期：可以修改或禁用三个默认快捷键；目录引用可通过搜索命令或资源管理器右键使用。
10. 在命令面板中执行“Codex Partner: 打开 Codex Partner 快捷键设置”。
   预期：打开键盘快捷方式页面，并自动筛选 `Codex Partner` 相关命令。
11. 按 `Ctrl+Alt+R`，输入部分文件名、目录名或父路径。
   预期：文件和目录显示在同一搜索列表中，使用不同图标，名称和父路径清晰可辨。
12. 选择一个文件或目录并按回车，再次打开搜索。
   预期：剪贴板得到对应引用；刚使用的条目显示在列表前部并标记为最近引用。
13. 使用包含两个根目录的工作区执行搜索并选择资源。
   预期：显示和复制的路径包含工作区名称，不会混淆两个根目录中的同名文件。
14. 对未保存文件、空选区或工作区外资源执行命令。
   预期：不写入错误引用，并显示可诊断错误。
