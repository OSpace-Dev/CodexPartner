## 人工验收协议

### 目的

确认标签和字数计数位于输入框边界内，控件圆角一致，且焦点、主题与窄侧栏表现清晰稳定。

### 准备

- 使用 VS Code 打开仓库根目录，按 `F5` 启动 `Run Codex Partner`。
- 点击 Activity Bar 中的 Codex Partner 图标打开内容记录面板。
- 验收失败时关闭 Extension Development Host 即可回退。

### 执行步骤

1. 查看空输入区。
   - 预期结果：“新内容”和 `0 / 20000` 位于同一个圆角输入框上部，提示文字和保存按钮均未与其重叠。
   - 证据：保留输入区截图。
2. 点击文本域并输入 `abc`，再使用 `Tab` 在可交互控件间移动。
   - 预期结果：计数更新为 `3 / 20000`；输入区整体显示清晰焦点边框；按钮获得独立且可见的键盘焦点。
   - 证据：记录计数结果，并保留焦点状态截图。
3. 将侧栏缩窄到约 220px，并输入多行内容。
   - 预期结果：标签、计数、文本、保存按钮均不溢出或相互遮挡，输入容器圆角边界连续。
   - 证据：保留窄侧栏截图。
4. 新建一条记录，检查保存、复制、删除和清空按钮，以及记录项和空状态。
   - 预期结果：各控件使用一致的 8px 圆角，输入容器使用更明显的 10px 圆角；悬停不会造成布局位移，原有操作行为不变。
   - 证据：记录操作结果，完成后删除测试记录。
5. 分别切换一个浅色主题和一个深色主题。
   - 预期结果：输入区边界、焦点状态、文字与按钮在两个主题下均清晰可辨。
   - 证据：各保留一张截图。

### 验收标准

- 通过：五个步骤全部符合预期，没有溢出、遮挡、焦点缺失或操作回归。
- 失败：标签或计数位于输入框外、圆角不一致、焦点不可辨、窄侧栏发生遮挡，或保存相关操作回归。
- 阻塞：无法启动 Extension Development Host，或本机策略禁止加载开发扩展。
