## 自动化覆盖

- 工作区索引加载为工作区相对文件和目录条目。
- 候选按标签、路径和父目录过滤，支持非连续字符的有序模糊匹配，并限制返回数量。
- 宿主搜索消息返回本地化完整引用字符串。
- 文件系统创建/删除会失效搜索缓存并通知打开中的菜单；新建空目录可进入候选，删除后移除。
- Webview HTML 包含仅展示候选的搜索浮层；脚本接线覆盖主输入框保持焦点、`#` 后草稿查询、搜索消息、Esc 关闭与重新触发、上下方向键循环选择、选中项滚动和回车选择；弹层固定高度并始终定位在触发光标上方。
- 执行 `npm run check`，覆盖语法检查与 Node.js 内置测试。

## Extension Host 人工验收协议

### 准备

- 在 VS Code 打开仓库，按 `F5` 启动 `Run Codex Partner`，打开 Codex Partner Activity Bar 面板。
- 准备一个包含多个目录、文件和较长路径的工作区。

### 步骤与预期

1. 在输入框开头输入 `#`。
   - 预期：搜索浮层紧邻光标上方出现，焦点仍在主输入框，显示工作区文件和目录候选；加载期间有明确状态。
2. 继续输入目录名或文件名的一部分。
   - 预期：字符继续出现在主输入框中，同时候选即时模糊过滤（包括非连续字符的有序匹配），显示名称、父目录和文件/目录类型；弹层保持固定高度，候选过多时只在内部滚动，位置不因数量变化跳动。
3. 使用上下方向键移动，再按 Enter。
   - 预期：上下方向键循环切换并滚动到选中候选；按 Enter 后选中项被插入为引用气泡，`#query` 被删除，光标位于气泡之后；不会直接保存整条记录。
4. 使用鼠标点击候选项。
   - 预期：同样插入气泡，输入框保持焦点和可继续编辑。
5. 保存记录并点击历史记录复制。
   - 预期：气泡展示为紧凑摘要，复制内容包含完整工作区相对路径。
6. 在英文/简体中文、浅色/深色主题、约 220px 窄侧栏中重复步骤 1–5。
   - 预期：候选浮层、图标、选中背景和气泡文字均清晰，不发生横向溢出或控件重叠。
7. 输入普通文本中的 `#`、按 Escape 关闭浮层、删除触发文本。
   - 预期：只有符合触发条件的 `#query` 打开搜索；Escape 关闭后仍在编辑器输入，菜单不会立即重开；继续编辑或移动光标后同一个 `#` 可再次触发。
8. 保持 `#` 菜单打开，在资源管理器中新建一个空目录，再删除它。
   - 预期：候选随创建/删除自动刷新；新建目录可搜索，删除后从候选消失，无需重载扩展。
9. 在浅色和深色主题下用上下键切换候选。
   - 预期：图标、名称、路径和类型标签在每行中垂直对齐，选中底色覆盖整行且文字清晰。
10. 输入连续名称片段、父目录片段和跨目录/名称的非连续字符查询。
   - 预期：候选名称和路径只高亮实际匹配字符；路径命中不误标为名称命中，选中状态下高亮仍可辨认。
11. 分别输入 `word#button`、`引用#目录`，并在已有文字后直接输入 `#`。
   - 预期：不需要先输入空格，`#` 出现后立即打开菜单，后续文字继续在输入框内过滤候选。
