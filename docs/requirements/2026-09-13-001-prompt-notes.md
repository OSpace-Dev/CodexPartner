# 本地内容记录面板

正文编号：REQ-20260913-001

## 范围

在 VS Code Explorer 侧栏提供一个独立的 Webview 内容记录面板。用户可以输入准备发送给 Codex 客户端的内容，点击“保存记录”后落地到扩展的 `workspaceState`，不创建 Codex 会话、不调用 Codex 接口。

每条已保存记录支持复制和删除；面板支持清空全部记录。记录按最新保存时间倒序展示，最多保留 200 条。

## 验收条件

- 面板可从 Explorer 打开，输入空白内容不会产生记录。
- 保存后内容在重载扩展或 VS Code 后仍可读取。
- 每条记录底部有复制按钮，复制内容只写入系统剪贴板。
- 删除和清空操作只影响本地记录，不影响 Codex 会话。
- `npm run check` 通过。

## 非目标与剩余风险

- 本版本不实现自动引用当前编辑器上下文，也不向 Codex 自动发送。
- 尚未在真实 VS Code Extension Host 中完成视觉人工验收；需要安装扩展后检查 Explorer 视图显示、窄侧栏换行和复制反馈。
