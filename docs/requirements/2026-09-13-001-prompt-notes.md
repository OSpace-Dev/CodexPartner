# 本地内容记录面板

正文编号：REQ-20260913-001

## 范围

在 VS Code Activity Bar 提供 Codex Partner 专属入口，点击后在独立侧栏容器中显示 Webview 内容记录面板。用户可以输入准备发送给 Codex 客户端的内容，点击“保存记录”后落地到扩展的 `workspaceState`，不创建 Codex 会话、不调用 Codex 接口。

每条已保存记录支持复制和删除；面板支持清空全部记录。记录按最新保存时间倒序展示，最多保留 200 条。

## 验收条件

- 安装扩展后，Activity Bar 显示 Codex Partner 专属图标；点击图标可打开内容记录面板。
- 面板不再占用 Explorer 折叠区域，输入空白内容不会产生记录。
- 保存后内容在重载扩展或 VS Code 后仍可读取。
- 每条记录底部有复制按钮，复制内容只写入系统剪贴板。
- 删除和清空操作只影响本地记录，不影响 Codex 会话。
- 面板文案随 VS Code 显示语言切换；提供英文和简体中文，未提供翻译的语言回退英文。
- 标题旁的键盘按钮打开 Codex Partner 快捷键设置，且图标在亮暗主题下不带蓝色底块。
- 输入区不显示“新内容”标签或字数计数，保留可供屏幕阅读器使用的输入标签；不设置显式字符上限。
- `npm run check` 通过。

## 非目标与剩余风险

- 本版本不实现自动引用当前编辑器上下文，也不向 Codex 自动发送。
- 不承诺无限存储容量；大文本仍受 VS Code `workspaceState`、Webview 状态、内存和性能约束。
- 尚未在真实 VS Code Extension Host 中完成视觉人工验收；需要安装扩展后检查 Activity Bar 入口、独立侧栏显示、窄侧栏换行和复制反馈。

## UI 更新

UI-20260913-001：使用 VS Code 主题变量、Lucide 风格内联 SVG、清晰的输入区/历史区层级、复制成功反馈和二次确认删除/清空。图标按钮提供 `aria-label` 与 `title`，支持窄侧栏换行和减少动效。

UI-20260919-001：将“新内容”标签与字数计数内嵌到输入框容器，保持标签与文本域的无障碍关联；输入容器使用 10px 圆角，按钮、记录项和空状态使用一致的 8px 圆角，并为完整输入容器提供聚焦反馈。

UI-20260919-002：替代 UI-20260919-001 的可见标签与计数设计。输入区只保留占位文字与屏幕阅读器标签，不再显示计数或限制字符；保留原有圆角与焦点反馈。关闭浏览器原生的右下角缩放手柄，改为从输入框上沿向上或向下拖动的高度抓手，允许在 82–180px 之间调整并记住当前 Webview 高度；抓手同时支持键盘方向键。标题图标使用主题前景色和透明背景；面板文案通过 VS Code 本地化接口适配显示语言，标题操作区增加带提示和无障碍名称的快捷键设置按钮。
