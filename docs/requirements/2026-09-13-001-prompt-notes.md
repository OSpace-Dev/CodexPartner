# 本地内容记录面板

正文编号：REQ-20260913-001

## 范围

在 VS Code Activity Bar 提供 Codex Partner 专属入口，点击后在独立侧栏容器中显示 Webview 内容记录面板。用户可以输入准备发送给 Codex 客户端的内容，点击“保存记录”后落地到扩展的 `workspaceState`，不创建 Codex 会话、不调用 Codex 接口。

每条已保存记录支持复制和删除；面板支持清空全部记录。记录按最新保存时间倒序展示，最多保留 200 条。

## 验收条件

- 安装扩展后，Activity Bar 显示 Codex Partner 专属图标；点击图标可打开内容记录面板。
- 面板不再占用 Explorer 折叠区域，输入空白内容不会产生记录。
- 保存后内容在重载扩展或 VS Code 后仍可读取。
- 每条记录底部有复制按钮，复制内容只写入系统剪贴板。
- 删除和清空操作只影响本地记录，不影响 Codex 会话。
- 面板文案随 VS Code 显示语言切换；提供英文和简体中文，未提供翻译的语言回退英文。
- 标题旁的键盘按钮打开 Codex Partner 快捷键设置，且图标在亮暗主题下不带蓝色底块。
- 输入区不显示“新内容”标签或字数计数，保留可供屏幕阅读器使用的输入标签；不设置显式字符上限。
- 在输入框输入 `#` 可在光标附近打开工作区文件/目录搜索；焦点留在主输入框，后续输入的 `#` 后文字保留在草稿中并模糊过滤候选；上下方向键循环切换并滚动候选，回车选择。Esc 关闭菜单且不会立即重新打开，继续输入或移动光标后可再次激活；弹层始终固定在触发光标上方并保持固定高度，候选列表在内部滚动，选择后以引用气泡插入完整路径。
- 工作区新增或删除文件、目录后，打开中的 `#` 菜单自动刷新候选；新建的空目录也应能被搜索。
- `npm run check` 通过。

## 非目标与剩余风险

- 本版本不实现自动引用当前编辑器上下文，也不向 Codex 自动发送。
- 不承诺无限存储容量；大文本仍受 VS Code `workspaceState`、Webview 状态、内存和性能约束。
- 尚未在真实 VS Code Extension Host 中完成视觉人工验收；需要安装扩展后检查 Activity Bar 入口、独立侧栏显示、窄侧栏换行和复制反馈。

## UI 更新

UI-20260913-001：使用 VS Code 主题变量、Lucide 风格内联 SVG、清晰的输入区/历史区层级、复制成功反馈和二次确认删除/清空。图标按钮提供 `aria-label` 与 `title`，支持窄侧栏换行和减少动效。

UI-20260919-001：将“新内容”标签与字数计数内嵌到输入框容器，保持标签与文本域的无障碍关联；输入容器使用 10px 圆角，按钮、记录项和空状态使用一致的 8px 圆角，并为完整输入容器提供聚焦反馈。

UI-20260919-002：替代 UI-20260919-001 的可见标签与计数设计。输入区只保留占位文字与屏幕阅读器标签，不再显示计数或限制字符；保留原有圆角与焦点反馈。关闭浏览器原生的右下角缩放手柄，改为从输入框上沿向上或向下拖动的高度抓手，允许在 82–180px 之间调整并记住当前 Webview 高度；抓手同时支持键盘方向键。标题图标使用主题前景色和透明背景；面板文案通过 VS Code 本地化接口适配显示语言，标题操作区增加带提示和无障碍名称的快捷键设置按钮。

UI-20260925-001：输入区改为富文本编辑器。插件生成的英文或简体中文文件/目录引用会解析为带文件/目录图标的紧凑气泡，长路径只显示可读后缀；历史记录采用相同展示。气泡节点保留完整原始引用，保存到 `workspaceState` 的 `note.content` 不变；编辑器选区复制和历史记录复制均返回完整引用文本。引用气泡使用原始文本作为提示和无障碍名称，未识别的普通文本保持原样。

UI-20260925-002：在富文本编辑器中输入 `#` 后，按当前光标位置显示工作区文件/目录搜索浮层；弹层打开后焦点移入内部搜索框，候选项支持继续输入过滤、上下方向键循环切换并自动滚动到选中项，回车选择；浮层始终锚定在触发光标上方并采用固定高度，候选列表独立滚动，不随候选数量变化跳动。选择后删除触发文本并插入引用气泡，仍使用完整引用字符串保存和复制；搜索浮层和候选项提供英文、简体中文文案及键盘可访问状态。

UI-20260925-003：Esc 关闭 `#` 搜索菜单并恢复编辑器焦点，不因同一次按键释放重新打开；继续编辑后允许再次触发。候选行统一图标、名称、路径和类型标签的垂直对齐，选中背景覆盖完整行。监听工作区创建与删除事件，失效搜索索引并刷新已打开菜单；新建空目录直接加入候选，删除后移除。

UI-20260925-004：替代 UI-20260925-002 的“弹层内搜索框”交互。输入焦点始终留在富文本编辑器，`#` 后的输入直接写入草稿并驱动候选模糊匹配；菜单仅展示列表。Esc 只跳过本次按键释放的重新触发，继续输入或调整光标仍可再次打开同一个 `#` 菜单。

UI-20260925-005：`#` 搜索候选在名称或路径中高亮实际命中的字符，包括非连续字符匹配，不将路径命中误标到名称上。输入区引用气泡与普通文字按正文基线对齐；鼠标进入或键盘聚焦时，气泡右侧显示可访问的删除按钮，点击后整体移除该引用并更新草稿，历史记录气泡保持只读。完整引用提示采用位于气泡上方的圆角浮层，避免被编辑器滚动区域裁切；保存和复制仍使用完整原始引用文本。

UI-20260925-006：无论 `#` 前是空格、普通文字还是中文字符，输入 `#` 即可触发引用搜索，不要求词边界。引用气泡的高度与编辑器正文行高一致，内部文字和图标垂直居中。暗色及暗色高对比度主题下，完整引用 tooltip 使用白底深字，并在底部显示指向气泡的小箭头；浅色主题沿用 VS Code 的 tooltip 主题色。

UI-20260925-007：引用气泡高度略低于正文行高；内部标签文字比正文小一档，图标与标签组成紧凑且垂直居中的整体，并与气泡外同一行的文字在视觉上对齐。输入区和历史记录使用相同排版。
