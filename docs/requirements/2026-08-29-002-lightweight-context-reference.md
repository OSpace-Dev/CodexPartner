# 轻量上下文引用需求

需求编号：`REQ-20260829-002`
状态：已确认实施范围

## 目标

继续使用官方 Codex VS Code 扩展作为聊天入口。本扩展只负责从 VS Code 工作区生成可直接粘贴的上下文引用，降低实现和维护成本，同时保留项目的核心卖点。

## 范围

- 编辑器非空选区生成文件路径和 1-based 行号范围。
- 编辑器右键菜单和 Code Action 灯泡提供选区入口。
- 资源管理器文件右键生成文件引用。
- 资源管理器目录右键生成目录引用。
- 生成结果自动复制到系统剪贴板，并给出轻量通知。

## 非目标

- 不维护 Codex 会话列表、会话历史、Composer 或消息流。
- 不读取 VS Code Cookie、Codex App 数据库、Token 或私有登录态。
- 不复制完整选中文本；引用通过工作区相对路径和行号引导 Codex。
- 不实现模型、推理强度、审批 UI 或 Markdown 消息渲染。

## 验收条件

1. 选中文件中的多行文本后，灯泡和编辑器右键菜单都能生成正确的相对路径和行号范围。
2. 选中单行文本时使用单行格式；跨行选区使用 `起始行-结束行` 格式。
3. 资源管理器中的文件和目录分别显示正确的复制命令。
4. 复制后系统剪贴板内容与通知中的引用一致，可以直接粘贴到官方 Codex 聊天框。
5. 工作区外、未保存文件、非法路径和无效选区不会生成引用，并显示可诊断错误。
6. `npm run check` 通过。
