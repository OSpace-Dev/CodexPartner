# 富文本引用气泡评审

编号：REV-20260925-001

评审对象：内容记录面板的富文本引用展示、完整文本持久化与复制行为。

需求依据：[本地内容记录面板](../requirements/2026-09-13-001-prompt-notes.md) 的 UI-20260925-001。

## 结论

实现范围符合需求：编辑器和历史记录通过同一解析器把支持的文件/目录引用转换为紧凑气泡；气泡通过 `data-reference` 保留原始字符串，保存消息仍使用完整文本，历史复制继续从宿主保存的完整 `note.content` 读取。

## 检查项

- 解析器支持英文和简体中文文件、目录、单行和行范围引用。
- 长路径仅压缩视觉标签，`raw`、`title`、`aria-label` 保留完整引用。
- 普通文本、换行和多个引用可以混排。
- 编辑器复制覆盖浏览器默认文本，写入完整引用文本。
- Webview HTML 通过受 CSP nonce 保护的脚本加载解析器，并提供文件/目录图标。

## 未检查内容

- 尚未在真实 VS Code Extension Host 中目视检查气泡在亮暗主题、极窄侧栏和删除/换行操作中的表现。
- 未引入浏览器 DOM 测试环境，因此编辑器选区复制和 contenteditable 的实际浏览器行为仍需人工验收。

## 残余风险

- 浏览器在 contenteditable 中自动生成的 `DIV`/`BR` 结构可能影响复杂选区复制时的换行归一化；完整记录复制路径不受此风险影响。
- 当前只识别扩展现有引用格式，其他 Markdown 链接或自定义引用不会转换为气泡。
